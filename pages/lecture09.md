# Lecture 09. LSTM과 GRU 소개

기본 RNN은 문장이 길어질수록 앞부분의 정보를 안정적으로 유지하기 어려울 수 있습니다. LSTM과 GRU는 게이트를 이용해 이전 정보와 새로운 정보의 반영 정도를 조절하도록 설계된 순환 신경망입니다.

## 학습 목표

- 기본 RNN의 장기 의존성 문제를 설명할 수 있습니다.
- LSTM의 셀 상태와 은닉 상태를 구분할 수 있습니다.
- 망각·입력·출력 게이트의 역할을 설명할 수 있습니다.
- 한 시점에서 LSTM의 정보가 갱신되는 순서를 설명할 수 있습니다.
- LSTM과 GRU의 공통점과 차이점을 비교할 수 있습니다.
- 모델 선택에는 검증 결과가 필요하다는 점을 이해할 수 있습니다.

---

## 1. RNN의 장기 의존성 문제

**장기 의존성(long-term dependency)**은 오래전에 나온 정보가 현재의 판단에 영향을 주는 관계를 뜻합니다.

![긴 문장에서 초기 정보가 약해지는 RNN의 장기 의존성 문제](assets/lec09_01_long_term_dependency.png)

```text
초기 정보 → h₁ → h₂ → h₃ → ··· → hₜ → 현재 판단
```

기본 RNN에서는 초기 정보가 여러 시점의 상태 갱신을 거치면서 약해질 수 있습니다. 학습 과정에서도 기울기가 앞쪽 시점으로 충분히 전달되지 않으면 멀리 떨어진 토큰 사이의 관계를 배우기 어렵습니다.

예를 들어 다음 문장에서 끝부분의 판단은 앞부분의 주어와 문맥에 영향을 받을 수 있습니다.

```text
처음에는 걱정했지만 여러 번 연습한 뒤 발표를 잘 마쳤다.
```

---

## 2. 왜 LSTM이 필요할까?

LSTM(Long Short-Term Memory)은 중요한 정보를 선택적으로 유지하고 불필요한 정보를 줄이도록 설계되었습니다.

![기본 RNN과 LSTM의 정보 전달 방식 비교](assets/lec09_02_rnn_lstm_memory.png)

기본 RNN이 하나의 은닉 상태를 계속 갱신한다면, LSTM은 별도의 셀 상태를 두고 게이트로 정보의 흐름을 조절합니다.

| 구조 | 상태 | 정보 조절 방식 |
|---|---|---|
| 기본 RNN | 은닉 상태 (h_t) | 매 시점 새로운 상태로 갱신 |
| LSTM | 셀 상태 (C_t), 은닉 상태 (h_t) | 게이트로 삭제·저장·출력을 조절 |

게이트는 0과 1 사이의 값을 만들어 정보가 얼마나 통과할지를 결정합니다.

---

## 3. 셀 상태와 은닉 상태

LSTM에는 서로 역할이 다른 두 상태가 있습니다.

![LSTM의 셀 상태와 은닉 상태를 두 종류의 메모로 비교](assets/lec09_03_cell_hidden_state.png)

| 상태 | 직관적인 역할 |
|---|---|
| 셀 상태 (C_t) | 비교적 오래 전달되는 장기 기억 |
| 은닉 상태 (h_t) | 현재 시점에서 외부와 다음 단계에 보여주는 정보 |

두 종류의 스티커 메모로 비유하면 다음과 같습니다.

- 셀 상태: 문장을 읽는 동안 비교적 오래 보관하는 핵심 메모
- 은닉 상태: 현재 단계에서 바로 사용할 요약 메모

셀 상태가 모든 정보를 그대로 보존하는 것은 아닙니다. 게이트가 이전 정보 중 남길 부분과 새로 추가할 부분을 학습합니다.

---

## 4. 망각 게이트: 무엇을 남길까?

망각 게이트(forget gate)는 이전 셀 상태의 각 정보를 얼마나 유지할지 결정합니다.

![LSTM 망각 게이트가 과거 기억의 유지 비율을 정하는 과정](assets/lec09_04_forget_gate.png)

$$
f_t = \sigma(W_f[h_{t-1}, x_t] + b_f)
$$

시그모이드 함수의 출력은 0과 1 사이입니다.

```text
0에 가까움 → 해당 정보를 대부분 삭제
1에 가까움 → 해당 정보를 대부분 유지
```

망각 게이트의 출력과 이전 셀 상태를 위치별로 곱합니다.

$$
f_t \odot C_{t-1}
$$

초급 단계에서는 “망각 게이트가 과거 기억의 유지 비율을 정한다”는 의미를 이해하는 것이 가장 중요합니다.

---

## 5. 입력 게이트: 무엇을 저장할까?

입력 게이트(input gate)는 새로운 정보 중 셀 상태에 반영할 비율을 결정합니다.

$$
i_t = \sigma(W_i[h_{t-1}, x_t] + b_i)
$$

새롭게 저장할 후보 기억도 함께 만듭니다.

$$
\widetilde{C}_t = \tanh(W_c[h_{t-1}, x_t] + b_c)
$$

입력 게이트 (i_t)와 후보 기억 \(\widetilde{C}_t\)를 곱하면 실제로 추가할 정보가 됩니다.

```text
새로운 후보 기억 × 저장 비율 = 실제로 추가할 정보
```

---

## 6. 출력 게이트: 무엇을 보여줄까?

출력 게이트(output gate)는 갱신된 셀 상태 중 현재 은닉 상태로 내보낼 정보를 결정합니다.

![LSTM 입력 게이트와 출력 게이트의 역할 비교](assets/lec09_05_input_output_gate.png)

$$
o_t = \sigma(W_o[h_{t-1}, x_t] + b_o)
$$

현재 은닉 상태는 다음과 같이 만들어집니다.

$$
h_t = o_t \odot \tanh(C_t)
$$

| 게이트 | 핵심 질문 | 역할 |
|---|---|---|
| 망각 게이트 | 과거 정보 중 무엇을 남길까? | 이전 기억의 유지 비율 결정 |
| 입력 게이트 | 새 정보 중 무엇을 저장할까? | 새로운 기억의 반영 비율 결정 |
| 출력 게이트 | 현재 기억에서 무엇을 보여줄까? | 은닉 상태로 보낼 비율 결정 |

---

## 7. 한 번의 LSTM 계산

한 시점의 LSTM은 다음 순서로 정보를 처리합니다.

![망각 저장 출력으로 이어지는 한 번의 LSTM 계산](assets/lec09_06_lstm_step.png)

### 1단계: 과거 기억에서 남길 부분 선택

$$
f_t \odot C_{t-1}
$$

### 2단계: 새로운 정보에서 추가할 부분 선택

$$
i_t \odot \widetilde{C}_t
$$

### 3단계: 셀 상태 갱신

$$
C_t = f_t \odot C_{t-1} + i_t \odot \widetilde{C}_t
$$

### 4단계: 현재 은닉 상태 생성

$$
h_t = o_t \odot \tanh(C_t)
$$

전체 계산을 외우기보다 다음 흐름을 이해하면 됩니다.

```text
과거 기억 일부 유지
       +
새로운 정보 일부 저장
       ↓
셀 상태 갱신
       ↓
현재 은닉 상태 출력
```

---

## 8. GRU: 더 단순한 게이트 구조

GRU(Gated Recurrent Unit)도 게이트를 사용해 이전 정보와 새로운 정보를 조절합니다. 하지만 LSTM보다 구조가 단순합니다.

- 별도의 셀 상태 없이 하나의 은닉 상태를 사용합니다.
- 업데이트 게이트와 리셋 게이트를 사용합니다.
- LSTM보다 학습할 파라미터가 적은 경우가 많습니다.

| GRU 게이트 | 직관적인 역할 |
|---|---|
| 업데이트 게이트 | 이전 정보와 새로운 정보를 어느 정도 섞을지 결정 |
| 리셋 게이트 | 새로운 후보 상태를 만들 때 이전 정보를 얼마나 사용할지 결정 |

GRU 역시 긴 문장의 정보를 항상 완벽하게 기억하는 것은 아닙니다. 게이트를 통해 기본 RNN보다 정보의 흐름을 조절하기 쉽게 만든 구조입니다.

## 9. LSTM과 GRU 비교

![LSTM과 GRU의 상태와 게이트 구조 비교](assets/lec09_07_lstm_gru_comparison.png)

| 항목 | LSTM | GRU |
|---|---|---|
| 상태 | 셀 상태와 은닉 상태 | 은닉 상태 하나 |
| 주요 게이트 | 망각·입력·출력 게이트 | 리셋·업데이트 게이트 |
| 구조 | 상대적으로 세밀함 | 상대적으로 단순함 |
| 파라미터 수 | 일반적으로 더 많음 | 일반적으로 더 적음 |
| 계산량 | 상대적으로 큼 | 상대적으로 작음 |

LSTM과 GRU 중 하나가 모든 데이터에서 항상 더 좋은 것은 아닙니다.

```text
모델 선택 = 검증 성능 + 학습 시간 + 모델 크기 + 오류 유형
```

복잡한 장기 패턴에서는 LSTM을 먼저 고려할 수 있고, 비교적 단순하고 빠른 모델이 필요하면 GRU를 먼저 시도할 수 있습니다. 최종 선택은 동일한 데이터 분할에서 직접 비교해 결정해야 합니다.

## 10. Keras에서 LSTM과 GRU 사용하기

Keras에서는 순환층의 이름만 바꾸어 기본 구조를 만들 수 있습니다.

```python
# LSTM
x = layers.LSTM(64)(x)
```

```python
# GRU
x = layers.GRU(64)(x)
```

`64`는 출력 은닉 상태 벡터의 크기입니다. 기본 설정에서는 마지막 유효 시점의 출력 벡터 하나를 반환합니다. Embedding층에서 `mask_zero=True`를 사용하면 PAD 시점의 상태 갱신을 건너뛸 수 있습니다.

```python
inputs = keras.Input(shape=(max_len,), dtype="int32")
x = layers.Embedding(vocab_size, 64, mask_zero=True)(inputs)
x = layers.LSTM(64)(x)  # 또는 layers.GRU(64)
feat = layers.Dense(16, activation="relu", name="feat")(x)
outputs = layers.Dense(3, activation="softmax")(feat)

model = keras.Model(inputs, outputs)
```

이번 장에서는 구조의 의미만 이해하고, 전체 학습 코드는 Lecture 10에서 실행합니다.

## 핵심 정리

- LSTM과 GRU는 게이트로 정보의 흐름을 조절합니다.
- LSTM은 셀 상태와 은닉 상태, 세 종류의 주요 게이트를 사용합니다.
- 망각 게이트는 유지, 입력 게이트는 저장, 출력 게이트는 공개할 정보를 결정합니다.
- GRU는 하나의 은닉 상태와 두 종류의 게이트를 사용하는 비교적 단순한 구조입니다.
- LSTM과 GRU 중 어느 모델이 더 좋은지는 검증 결과를 통해 판단해야 합니다.
