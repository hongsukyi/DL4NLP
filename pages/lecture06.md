# Lecture 06. 텍스트 처리를 위한 1D CNN 이해

CNN(Convolutional Neural Network)은 이미지뿐 아니라 텍스트에도 사용할 수 있습니다. 텍스트용 1D CNN은 문장에서 서로 이웃한 토큰을 함께 살펴보고, 분류에 도움이 되는 짧은 구절의 패턴을 찾습니다.

## 학습 목표

- 텍스트에서 1D CNN이 찾는 지역 패턴을 설명할 수 있습니다.
- 임베딩 출력과 PyTorch `Conv1d` 입력의 형태를 구분할 수 있습니다.
- 커널 크기, 스트라이드, 패딩의 역할을 설명할 수 있습니다.
- 입력 채널 수와 필터 수의 차이를 설명할 수 있습니다.
- ReLU와 맥스 풀링의 역할을 설명할 수 있습니다.
- 1D CNN 문장 분류 모델의 전체 구조를 설명할 수 있습니다.

---

## 1. 텍스트를 위한 1D CNN

텍스트용 1D CNN은 문장의 짧은 구간을 이동하며 특징을 찾습니다. 찾은 특징을 모아 문장을 하나의 벡터로 요약하고, 이 벡터를 이용해 범주를 예측할 수 있습니다.

![텍스트를 처리하는 1D CNN의 전체 개념](assets/lec06_01_text_cnn_overview.png)

```text
문장
  ↓
토큰 ID
  ↓
임베딩
  ↓
Conv1D와 ReLU
  ↓
글로벌 맥스 풀링
  ↓
문장 분류
```

> **핵심:** 1D CNN은 문장 전체를 한 번에 보는 것이 아니라, 작은 토큰 구간을 이동하며 유용한 패턴을 찾습니다.

---

## 2. CNN은 지역 패턴을 찾는다

CNN이 한 번에 살펴보는 작은 영역을 **지역 영역(local region)**이라고 합니다. 텍스트에서는 서로 이웃한 여러 토큰이 하나의 지역 영역이 됩니다.

![서로 이웃한 토큰에서 지역 패턴을 찾는 과정](assets/lec06_02_local_patterns.png)

다음 문장을 예로 살펴봅시다.

```text
이 영화는 정말 매우 재미있다
```

커널 크기가 3이라면 CNN은 다음과 같은 연속된 토큰 구간을 차례대로 살펴볼 수 있습니다.

```text
[이, 영화는, 정말]
[영화는, 정말, 매우]
[정말, 매우, 재미있다]
```

`정말 매우 재미있다`처럼 인접한 토큰의 조합은 문장 분류에 유용한 단서가 될 수 있습니다. CNN은 이러한 구간을 단순히 세는 것이 아니라, 임베딩 벡터 위에서 작업에 도움이 되는 패턴을 학습합니다.

---

## 3. 텍스트에 CNN을 사용하는 이유

텍스트용 CNN의 주요 특징은 다음과 같습니다.

- 서로 이웃한 토큰을 함께 살펴봅니다.
- 같은 필터를 문장의 여러 위치에서 재사용합니다.
- 짧은 구절의 패턴을 효율적으로 찾을 수 있습니다.
- 여러 필터를 사용해 서로 다른 종류의 특징을 학습할 수 있습니다.

같은 표현이 문장의 다른 위치에 나타나도 동일한 필터가 반응할 수 있습니다.

```text
이 영화는 정말 재미있다
정말 재미있는 영화를 보았다
```

두 문장에서 `정말 재미있`에 가까운 패턴의 위치는 다르지만, 같은 필터가 두 위치를 모두 살펴볼 수 있습니다.

---

## 4. 임베딩과 Conv1D 입력

각 토큰은 여러 실수로 이루어진 임베딩 벡터를 가집니다. 여러 토큰의 임베딩을 모으면 하나의 행렬이 만들어집니다.

![임베딩 출력과 PyTorch Conv1d 입력 형태](assets/lec06_03_embedding_conv1d_input.png)

배치 크기가 32, 문장 길이가 20, 임베딩 차원이 64라면 임베딩 층의 출력 크기는 다음과 같습니다.

```text
[batch, sequence_length, embedding_dim]
[32, 20, 64]
```

그러나 PyTorch의 `nn.Conv1d`는 다음 순서의 입력을 사용합니다.

```text
[batch, channels, length]
[32, 64, 20]
```

따라서 임베딩 출력의 두 축을 바꿔야 합니다.

```python
x = embedding(input_ids)   # [batch, length, embedding_dim]
x = x.transpose(1, 2)      # [batch, embedding_dim, length]
x = conv1d(x)
```

이 구조에서는 임베딩 차원 `64`가 Conv1D의 입력 채널 수가 되고, 토큰이 나열된 문장 길이 방향으로 필터가 이동합니다.

---

## 5. 합성곱으로 특징값 만들기

합성곱은 입력의 작은 구간과 필터의 값을 같은 위치끼리 곱한 뒤 모두 더합니다. 여기에 편향을 더하면 한 위치의 특징값이 만들어집니다.

![입력 구간과 필터로 특징값을 계산하는 과정](assets/lec06_04_convolution_calculation.png)

간단한 1차원 예를 살펴봅시다.

```text
입력 구간: [1, 2, 0]
필터:      [1, 0, -1]
편향:       0.5
```

특징값은 다음과 같이 계산됩니다.

$$
(1 \times 1) + (2 \times 0) + (0 \times -1) + 0.5 = 1.5
$$

필터를 다음 위치로 옮겨 같은 계산을 반복하면 여러 특징값이 만들어지고, 이를 **특징 맵(feature map)**이라고 합니다. 실제 텍스트 CNN에서는 각 토큰이 벡터이므로 필터도 임베딩 차원을 함께 사용합니다.

---

## 6. 커널 크기: 한 번에 보는 범위

**커널 크기(kernel size)**는 필터가 한 번에 살펴보는 연속된 토큰 위치의 수입니다.

| 커널 크기 | 살펴보는 범위 | 직관적 해석 |
|---:|---|---|
| 2 | 토큰 2개 | 짧은 연결 관계 |
| 3 | 토큰 3개 | 세 토큰의 구절 패턴 |
| 5 | 토큰 5개 | 더 긴 지역 문맥 |

커널 크기가 클수록 한 번에 더 넓은 구간을 보지만, 항상 큰 값이 좋은 것은 아닙니다. 문장 길이, 데이터 양, 찾으려는 패턴을 고려해 선택해야 합니다.

커널 크기를 n-gram에 비유할 수 있지만 두 개념은 동일하지 않습니다. n-gram은 토큰 조합을 직접 세는 방식이고, CNN은 임베딩 구간에 적용되는 가중치를 학습합니다.

---

## 7. 스트라이드: 몇 칸씩 이동할까?

**스트라이드(stride)**는 필터가 한 번 계산한 뒤 다음 위치로 몇 칸 이동하는지를 나타냅니다.

![Stride 1과 Stride 2의 이동 간격 비교](assets/lec06_05_stride_padding.png)

- Stride 1: 필터가 한 칸씩 이동합니다.
- Stride 2: 필터가 두 칸씩 이동합니다.

같은 입력 길이와 커널 크기에서는 스트라이드가 커질수록 계산하는 위치와 출력 길이가 줄어듭니다. 텍스트 CNN에서는 인접한 정보를 놓치지 않도록 Stride 1을 자주 사용합니다.

---

## 8. 패딩: 출력 길이 조절하기

**패딩(padding)**은 입력의 양 끝에 값을 추가하여 합성곱의 출력 길이와 경계 처리 방식을 조절하는 방법입니다.

| 방식 | 설명 |
|---|---|
| Valid | 경계 패딩을 추가하지 않음 |
| Same | 일반적으로 Stride 1에서 출력 길이를 입력 길이와 같게 유지 |

패딩이 없으면 필터가 문장 양 끝을 충분히 중심에 놓고 계산하기 어렵습니다. 패딩을 추가하면 경계에 있는 토큰도 더 균형 있게 처리할 수 있습니다.

PyTorch에서는 커널 크기가 홀수이고 Stride가 1일 때 다음처럼 길이를 유지할 수 있습니다.

```python
kernel_size = 3
conv = nn.Conv1d(
    in_channels=64,
    out_channels=64,
    kernel_size=kernel_size,
    padding=kernel_size // 2
)
```

> 입력 토큰화 단계의 PAD 토큰과 합성곱 경계에 추가하는 convolution padding은 목적이 다릅니다.

---

## 9. 입력 채널과 필터 수

입력 채널 수와 필터 수는 서로 다른 값을 나타냅니다.

![입력 채널과 여러 Conv1D 필터의 관계](assets/lec06_06_channels_filters.png)

- **입력 채널 수:** Conv1D에 들어오는 특징의 수입니다. 텍스트 모델에서는 일반적으로 임베딩 차원과 같습니다.
- **필터 수:** 모델이 학습할 필터의 개수입니다. Conv1D의 출력 채널 수가 됩니다.
- **필터 가중치:** 학습 과정에서 분류에 도움이 되도록 조정됩니다.

예를 들어 임베딩 차원이 64이고 필터가 128개라면 다음처럼 설정할 수 있습니다.

```python
conv = nn.Conv1d(
    in_channels=64,
    out_channels=128,
    kernel_size=3
)
```

출력에는 위치마다 128개의 특징값이 생성됩니다.

---

## 10. ReLU: 음수는 0, 양수는 그대로

합성곱 뒤에는 일반적으로 ReLU 활성화함수를 적용합니다.

$$
\operatorname{ReLU}(z) = \max(0, z)
$$

```text
합성곱 출력: [-1.2, 0.5, -0.3, 2.1, 0.0]
ReLU 출력:   [ 0.0, 0.5,  0.0, 2.1, 0.0]
```

ReLU는 음수를 0으로 만들고 양수는 그대로 유지합니다. 이를 통해 모델에 비선형성을 추가하여 더 복잡한 특징을 학습할 수 있게 합니다.

---

## 11. 맥스 풀링과 글로벌 맥스 풀링

**맥스 풀링(max pooling)**은 정해진 구간마다 가장 큰 값을 선택하여 특징의 길이를 줄입니다.

![맥스 풀링과 글로벌 맥스 풀링 비교](assets/lec06_07_max_pooling.png)

```text
입력: [1, 5, 2, 9, 3, 4]
구간별 맥스 풀링: [5, 9, 4]
```

**글로벌 맥스 풀링(Global Max Pooling, GMP)**은 각 출력 채널에서 문장 전체 위치 중 가장 큰 값 하나를 선택합니다.

```text
채널 1: [0.1, 0.9, 0.2, 0.5] → 0.9
채널 2: [0.4, 0.3, 0.7, 0.6] → 0.7
채널 3: [0.8, 0.2, 0.1, 0.3] → 0.8
```

출력 채널이 128개라면 글로벌 맥스 풀링 이후에는 128개의 값으로 이루어진 문장 벡터가 만들어집니다.

> `GAP`는 일반적으로 Global Average Pooling을 의미합니다. 글로벌 최댓값 풀링은 `Global Max Pooling` 또는 `GMP`로 표기하는 것이 명확합니다.

---

## 12. 위치가 달라도 같은 패턴 찾기

같은 필터는 문장의 모든 위치에서 재사용됩니다. 따라서 비슷한 구절이 다른 위치에 있어도 같은 필터가 반응할 수 있습니다.

글로벌 맥스 풀링은 각 특징이 가장 강하게 나타난 위치의 값을 선택합니다. 이에 따라 패턴의 정확한 위치보다 해당 패턴이 존재하는지가 더 중요하게 반영될 수 있습니다.

그러나 이것이 CNN이 단어 순서를 완전히 무시한다는 뜻은 아닙니다. 합성곱은 각 지역 구간 안에서 토큰의 배열을 구분합니다. 글로벌 풀링 단계에서 문장 전체의 세부 위치 정보가 요약되는 것입니다.

---

## 13. CNN 문장 분류의 전체 구조

![1D CNN 문장 분류 모델의 전체 구조](assets/lec06_08_cnn_classifier.png)

1D CNN 문장 분류 모델은 다음 순서로 작동합니다.

1. 토큰 ID를 임베딩 벡터로 변환합니다.
2. 임베딩 출력의 축을 PyTorch `Conv1d` 입력에 맞게 바꿉니다.
3. Conv1D로 위치별 지역 특징을 만듭니다.
4. ReLU로 비선형성을 추가합니다.
5. 글로벌 맥스 풀링으로 채널별 대표값을 선택합니다.
6. 완전연결층(`nn.Linear`)으로 범주별 점수를 계산합니다.

```text
토큰 ID
→ 임베딩
→ 축 변환
→ Conv1D
→ ReLU
→ 글로벌 맥스 풀링
→ 완전연결층
→ 분류 점수
```

## 14. 다음 실습의 모델 설정

다음 실습에서는 같은 데이터로 Flatten, 평균 풀링, Conv1D 모델을 비교합니다. Conv1D 모델은 다음 설정을 사용합니다.

| 항목 | 값 | 의미 |
|---|---:|---|
| 임베딩 차원 | 64 | 토큰 하나를 64개 값으로 표현 |
| 커널 크기 | 3 | 한 번에 인접한 토큰 위치 3개를 확인 |
| 필터 수 | 64 | 위치마다 64개 특징 채널 생성 |
| 스트라이드 | 1 | 필터가 한 칸씩 이동 |

다른 커널 크기나 필터 수도 사용할 수 있지만, 모델을 공정하게 비교하려면 실습 코드와 설명에서 동일한 설정을 유지해야 합니다.

## 15. 학습 결과를 해석할 때

훈련 손실과 검증 손실을 함께 확인해야 합니다. 훈련 손실이 계속 감소하더라도 검증 손실이 다시 증가하면 과적합 가능성이 있습니다.

문장 벡터를 t-SNE로 2차원에 표시하여 범주별 분포를 탐색할 수도 있습니다. 그러나 벡터 그림과 실제 분류 성능은 구분해서 해석해야 합니다.

- 학습 곡선: 훈련 과정과 과적합 경향 확인
- Accuracy와 혼동행렬: 테스트 데이터의 분류 성능 평가
- t-SNE: 문장 벡터의 관계를 탐색하는 보조 시각화

## 핵심 정리

- 1D CNN은 서로 이웃한 토큰의 지역 패턴을 학습합니다.
- PyTorch `Conv1d`의 입력은 `[batch, channels, length]` 순서입니다.
- 커널 크기는 한 번에 보는 토큰 위치 수입니다.
- 스트라이드는 필터의 이동 간격이고, 패딩은 출력 길이와 경계 처리를 조절합니다.
- 입력 채널 수는 임베딩 차원과 연결되고, 필터 수는 출력 채널 수를 결정합니다.
- 글로벌 맥스 풀링은 각 채널에서 문장 전체 위치의 최댓값 하나를 선택합니다.
- CNN은 지역 구간의 순서를 활용하지만, 글로벌 풀링에서는 세부 위치 정보가 요약됩니다.
