# Lecture 08. RNN 기반 문장 분류

RNN(Recurrent Neural Network)은 문장의 토큰을 순서대로 읽으며 이전 단계의 정보를 다음 단계로 전달합니다. 이번 장에서는 RNN이 순서를 처리하는 방법과 은닉 상태의 의미를 이해하고, 문장 분류에 사용하는 전체 흐름을 살펴봅니다.

## 학습 목표

- MLP, CNN, RNN이 문장을 처리하는 방식의 차이를 설명할 수 있습니다.
- 은닉 상태가 이전 정보와 현재 입력을 결합하는 과정을 설명할 수 있습니다.
- RNN을 시간축으로 펼친 구조와 가중치 공유를 이해할 수 있습니다.
- 마지막 유효 은닉 상태를 문장 분류에 사용하는 이유를 설명할 수 있습니다.
- BPTT와 장기 의존성 문제를 직관적으로 설명할 수 있습니다.
- Keras `SimpleRNN`의 `units`와 기본 출력을 설명할 수 있습니다.

---

## 1. RNN 기반 문장 분류

RNN은 토큰을 앞에서부터 하나씩 읽습니다. 각 단계에서 현재 토큰과 앞에서 전달된 정보를 함께 사용해 새로운 상태를 만듭니다.

![RNN으로 문장을 순서대로 읽고 분류하는 과정](https://cdn.jsdelivr.net/gh/hongsukyi/DL4NLP@main/assets/lec08_01_rnn_overview.png)

```text
문장
  ↓
토큰 ID
  ↓
임베딩 벡터의 순서
  ↓
RNN이 토큰을 차례대로 처리
  ↓
문장 벡터
  ↓
면접 / 학교 / 협상
```

RNN의 중요한 특징은 현재 토큰만 보는 것이 아니라, 앞에서 계산한 상태를 다음 토큰을 처리할 때 다시 사용한다는 점입니다.

---

## 2. MLP·CNN·RNN은 무엇을 다르게 볼까?

모델마다 문장에서 정보를 모으는 방식이 다릅니다.

![Flatten Masked GAP CNN RNN의 문장 처리 방식 비교](https://cdn.jsdelivr.net/gh/hongsukyi/DL4NLP@main/assets/lec08_02_model_comparison.png)

| 모델 | 문장을 처리하는 대표적인 방식 |
|---|---|
| MLP + Flatten | 모든 토큰 위치의 임베딩을 한 줄로 펼침 |
| MLP + Masked GAP | PAD를 제외한 토큰 임베딩의 평균을 사용 |
| CNN | 이웃한 토큰 구간에서 지역 패턴을 찾음 |
| RNN | 이전 상태를 이어받으며 토큰을 순서대로 처리 |

이 구분은 각 모델의 핵심적인 차이를 이해하기 위한 단순화입니다. 실제로 모델이 학습하는 정보는 데이터와 구조에 따라 달라질 수 있습니다.

---

## 3. 같은 단어도 순서가 달라지면 의미가 달라진다

문장에 포함된 단어가 같아도 순서가 바뀌면 의미가 달라질 수 있습니다.

![같은 단어의 순서에 따라 문장 의미가 달라지는 예](https://cdn.jsdelivr.net/gh/hongsukyi/DL4NLP@main/assets/lec08_03_word_order.png)

```text
개가 사람을 문다.
사람이 개를 문다.
```

두 문장은 비슷한 단어를 사용하지만 행동의 주체와 대상이 반대입니다. 단어를 단순히 평균하면 이러한 차이가 약해질 수 있습니다. RNN은 토큰이 나타나는 순서에 따라 상태를 갱신하므로 순서 정보를 처리할 수 있습니다.

---

## 4. 은닉 상태: 앞의 정보와 현재 입력 결합하기

RNN은 각 시점마다 **은닉 상태(hidden state)**를 계산합니다.

![이전 은닉 상태와 현재 입력으로 새 은닉 상태를 만드는 과정](https://cdn.jsdelivr.net/gh/hongsukyi/DL4NLP@main/assets/lec08_04_hidden_state.png)

시점 (t)의 은닉 상태는 다음 두 정보를 함께 사용합니다.

- 이전 은닉 상태 (h_{t-1}): 앞에서 읽은 토큰의 정보
- 현재 입력 (x_t): 현재 토큰의 임베딩 벡터

기본 RNN의 은닉 상태는 다음처럼 표현할 수 있습니다.

$$
h_t = \tanh(W_h h_{t-1} + W_x x_t + b)
$$

| 기호 | 의미 |
|---|---|
| (x_t) | 현재 시점의 입력 벡터 |
| (h_{t-1}) | 이전 시점의 은닉 상태 |
| (h_t) | 새롭게 계산한 은닉 상태 |
| (W_h, W_x, b) | 학습되는 가중치와 편향 |

수식의 세부 계산보다 중요한 점은 **이전 정보와 현재 입력을 결합하여 새로운 상태를 만든다**는 것입니다.

---

## 5. 스티커 메모로 이해하는 은닉 상태

은닉 상태를 문장을 읽으며 계속 고쳐 쓰는 스티커 메모에 비유할 수 있습니다.

```text
이전 메모 + 새 토큰 → 수정된 메모
```

예를 들어 `오늘 날씨가 정말 좋다`라는 문장을 읽는다고 생각해 봅시다.

| 읽은 토큰 | 은닉 상태에 담길 수 있는 정보 |
|---|---|
| 오늘 | 시간에 관한 정보 |
| 날씨가 | 주제가 날씨라는 정보 |
| 정말 | 강조 정보 |
| 좋다 | 긍정적인 상태 |

메모의 크기는 매 시점 같지만, 안에 담긴 값은 토큰을 읽을 때마다 달라집니다. 은닉 상태는 문장을 그대로 저장하는 공간이 아니라, 학습 목적에 도움이 되는 정보를 압축한 벡터입니다.

## 6. Unrolling과 가중치 공유

하나의 RNN 셀을 토큰 순서에 따라 펼쳐 그린 것을 **Unrolling**이라고 합니다.

![RNN을 시간축으로 펼치고 같은 가중치를 재사용하는 구조](https://cdn.jsdelivr.net/gh/hongsukyi/DL4NLP@main/assets/lec08_05_unrolling_weight_sharing.png)

```text
x₁ → RNN → h₁
             ↓
x₂ → RNN → h₂
             ↓
x₃ → RNN → h₃
             ↓
x₄ → RNN → h₄
```

그림에서는 여러 RNN 셀이 있는 것처럼 보이지만 실제로는 모든 시점에서 **같은 가중치**를 사용합니다.

- 계산 규칙은 모든 위치에서 같습니다.
- 입력 토큰과 이전 은닉 상태는 시점마다 달라집니다.
- 문장 길이가 달라도 같은 RNN을 반복해서 사용할 수 있습니다.

가중치 공유는 모델이 토큰 위치마다 별도의 계산 규칙을 만들지 않도록 합니다.

## 7. 마지막 은닉 상태에서 문장 분류까지

문장을 모두 읽은 뒤 마지막 유효 토큰까지의 은닉 상태를 문장 벡터로 사용할 수 있습니다.

![마지막 유효 은닉 상태를 이용한 문장 분류](https://cdn.jsdelivr.net/gh/hongsukyi/DL4NLP@main/assets/lec08_06_hidden_to_classification.png)

```text
토큰 임베딩 순서
       ↓
RNN 은닉 상태 h₁, h₂, …, hₜ
       ↓
마지막 유효 은닉 상태
       ↓
Dense층
       ↓
범주별 확률
```

PAD가 포함된 배치에서는 Masking을 사용해야 합니다. 그러면 PAD 시점의 상태 갱신을 건너뛰고 마지막 **실제 토큰**까지 처리한 상태를 사용할 수 있습니다.

Keras에서는 다음과 같이 구성할 수 있습니다.

```python
inputs = keras.Input(shape=(max_len,), dtype="int32")
x = layers.Embedding(vocab_size, 64, mask_zero=True)(inputs)
x = layers.SimpleRNN(32)(x)
outputs = layers.Dense(3, activation="softmax")(x)

model = keras.Model(inputs, outputs)
```

## 8. BPTT: 시간축을 따라 학습하기

RNN도 예측과 정답의 차이를 줄이도록 가중치를 학습합니다. RNN에서는 여러 시점에 같은 가중치가 사용되기 때문에 시간축의 계산을 거꾸로 따라가며 기울기를 계산합니다.

![RNN의 시간축 역전파와 장기 의존성 문제](https://cdn.jsdelivr.net/gh/hongsukyi/DL4NLP@main/assets/lec08_07_bptt_long_dependency.png)

이 과정을 **BPTT(Backpropagation Through Time)**라고 합니다.

```text
순전파:  x₁ → h₁ → h₂ → h₃ → 예측 → 손실
역전파:  손실에서 시작해 h₃ → h₂ → h₁ 방향으로 기울기 전달
```

각 시점에서 계산된 기울기는 모든 시점이 공유하는 RNN 가중치의 학습에 함께 사용됩니다.

---

## 9. 기본 RNN과 장기 의존성 문제

문장이 길어지면 초기 토큰의 정보가 여러 은닉 상태를 거쳐야 합니다. 이 과정에서 오래전 정보와 현재 정보의 관계를 학습하기 어려워질 수 있습니다.

- 기울기가 반복해서 작아지면 앞쪽 시점까지 학습 신호가 충분히 전달되지 않습니다.
- 이를 **기울기 소실(vanishing gradient)**이라고 합니다.
- 반대로 기울기가 지나치게 커지는 기울기 폭주가 발생할 수도 있습니다.

초급 단계에서는 다음과 같이 이해하면 충분합니다.

> 기본 RNN은 가까운 순서 정보는 처리할 수 있지만, 매우 오래전 정보를 안정적으로 유지하기 어려울 수 있습니다.

이 문제를 완화하기 위해 정보를 선택적으로 유지하는 LSTM과 GRU가 사용됩니다.

## 10. Keras SimpleRNN의 units

Keras의 `SimpleRNN`에서 `units`는 은닉 상태 벡터의 크기를 나타냅니다.

![Keras SimpleRNN의 units와 출력 벡터](https://cdn.jsdelivr.net/gh/hongsukyi/DL4NLP@main/assets/lec08_08_keras_simplernn.png)

```python
x = layers.SimpleRNN(units=32)(x)
```

이 설정의 의미는 다음과 같습니다.

```text
각 시점의 은닉 상태 크기 = 32
기본 반환값의 크기 = [batch, 32]
```

기본 설정인 `return_sequences=False`에서는 마지막 유효 시점의 출력 벡터 하나를 반환합니다.

```python
# 모든 시점의 출력을 반환
x = layers.SimpleRNN(32, return_sequences=True)(x)
```

이 경우 출력 크기는 `[batch, sequence_length, 32]`가 됩니다.

## 11. 학습 결과를 읽을 때 주의할 점

RNN 모델도 훈련 Loss와 검증 Loss를 함께 확인해야 합니다.

- 훈련 Loss만 계속 감소한다고 좋은 모델은 아닙니다.
- 검증 Loss가 다시 증가하면 과적합이 시작되었을 가능성이 있습니다.
- Early Stopping으로 검증 Loss가 가장 좋았던 가중치를 복원할 수 있습니다.
- t-SNE 그림은 문장 표현의 분포를 탐색하는 도구이며 성능 지표를 대신하지 않습니다.

테스트 정확도는 실행 환경과 학습 과정에 따라 달라질 수 있습니다. 따라서 슬라이드에 고정된 숫자를 외우기보다 현재 실행의 학습곡선, Accuracy, 혼동행렬을 함께 해석해야 합니다.

## 핵심 정리

- 문장 분류에서는 마지막 유효 은닉 상태를 문장 벡터로 사용할 수 있습니다.
- BPTT는 시간축을 거슬러 기울기를 계산하는 학습 방법입니다.
- 기본 RNN은 긴 문장에서 오래전 정보를 학습하기 어려울 수 있습니다.
