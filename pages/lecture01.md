# Lecture 01. 딥러닝 기반 NLP 개요

자연어 처리(Natural Language Processing, NLP)는 사람이 사용하는 언어를 컴퓨터가 분석하고 처리할 수 있도록 만드는 인공지능 기술입니다. 이번 강의에서는 문장이 어떻게 숫자로 바뀌고, 딥러닝 모델이 문맥을 학습하며, 언어 모델이 새로운 문장을 생성하는지 전체 흐름을 살펴봅니다.

## 학습 목표

이번 강의를 마치면 다음 내용을 설명할 수 있습니다.

- 자연어 처리의 의미와 대표적인 활용 분야를 설명할 수 있습니다.
- 문장이 토큰, 숫자 ID, 벡터로 변환되는 과정을 구분할 수 있습니다.
- 임베딩, RNN, LSTM, Attention, Transformer의 역할을 간단히 설명할 수 있습니다.
- 딥러닝 모델의 학습과 추론을 구분할 수 있습니다.
- BERT와 GPT의 기본적인 차이를 설명할 수 있습니다.

---

## 1. NLP란 무엇인가?

자연어란 한국어와 영어처럼 사람이 일상에서 사용하는 언어를 말합니다. 자연어 처리는 이러한 언어를 컴퓨터가 읽고 분석하며, 적절한 결과를 만들 수 있도록 연결하는 기술입니다.

![사람의 언어와 컴퓨터를 연결하는 NLP](assets/lec01_01_nlp_overview.png)

예를 들어 사람이 컴퓨터에 “오늘 날씨를 알려줘”라고 질문하면, 컴퓨터는 문장의 단어와 의도를 분석한 뒤 적절한 정보를 찾아 응답해야 합니다. 이 과정에 자연어 처리 기술이 사용됩니다.

자연어 처리는 다음과 같은 서비스의 기초가 됩니다.

- 번역
- 문서 분류
- 감정 분석
- 질의응답
- 문서 요약
- 대화와 문장 생성

> **핵심:** NLP는 사람의 언어와 컴퓨터를 연결하는 기술입니다.

---

## 2. NLP는 어떤 일을 할까?

하나의 문장도 작업 목적에 따라 서로 다른 방식으로 처리할 수 있습니다.

![분류, 번역, 질의응답의 예](assets/lec01_02_nlp_tasks.png)

예를 들어 “이 영화는 정말 재미있다.”라는 문장을 다음과 같이 활용할 수 있습니다.

- **분류:** 문장의 감정을 `긍정`으로 판단합니다.
- **번역:** 문장을 다른 언어로 바꿉니다.
- **질의응답:** 사용자의 질문에 알맞은 답변을 찾거나 생성합니다.
- **요약:** 긴 문서에서 중요한 내용을 짧게 정리합니다.

따라서 자연어 처리 모델의 출력 형태는 해결하려는 문제에 따라 달라집니다.

---

## 3. 사람의 언어는 왜 어려울까?

사람은 문장의 상황과 앞뒤 내용을 자연스럽게 고려하지만, 컴퓨터는 이를 명시적으로 학습해야 합니다. 특히 같은 단어도 문맥에 따라 의미가 달라질 수 있습니다.

![문맥에 따라 의미가 달라지는 단어](assets/lec01_03_context.png)

다음 두 문장에서 `은행`의 의미를 비교해 봅시다.

- “은행에서 돈을 찾았다.”
- “가을에 은행나무 잎이 노랗게 변했다.”

첫 번째 문장의 은행은 금융기관을 의미하고, 두 번째 문장의 은행은 나무를 의미합니다. 단어 하나만 보면 두 의미를 구분하기 어렵지만, 주변 단어를 함께 보면 어떤 뜻인지 판단할 수 있습니다.

또한 단어의 순서가 달라지면 문장의 의미도 달라질 수 있습니다.

- “경찰이 용의자를 찾았다.”
- “용의자가 경찰을 찾았다.”

두 문장은 같은 단어를 사용하지만, 단어의 순서와 문장 속 역할이 다르기 때문에 의미도 달라집니다.

> **핵심:** 자연어를 이해하려면 개별 단어뿐 아니라 단어의 순서와 전체 문맥을 함께 살펴봐야 합니다.

---

## 4. 문장은 어떻게 모델의 입력이 될까?

딥러닝 모델은 문장을 그대로 계산할 수 없습니다. 따라서 문장을 작은 단위로 나누고 숫자로 변환해야 합니다.

![문장이 모델 입력으로 변환되는 과정](assets/lec01_04_text_to_input.png)

문장은 일반적으로 다음 과정을 거쳐 모델의 입력이 됩니다.

1. 문장을 **토큰(token)**으로 나눕니다.
2. 각 토큰을 **숫자 ID**로 변환합니다.
3. 숫자 ID를 **벡터(vector)**로 변환합니다.
4. 만들어진 벡터를 딥러닝 모델에 입력합니다.

예를 들어 다음 문장을 생각해 봅시다.

```text
나는 오늘 학교에 갔다.
```

단어를 기준으로 단순하게 나누면 다음과 같은 토큰을 얻을 수 있습니다.

```text
[나는, 오늘, 학교에, 갔다, .]
```

어휘집에 따라 각 토큰에 번호를 부여하면 다음과 같이 표현할 수 있습니다.

```text
[12, 87, 304, 15, 3]
```

이 숫자는 토큰을 구분하기 위한 식별 번호입니다. `304`라는 숫자가 `12`보다 더 중요하거나 더 큰 의미를 나타내는 것은 아닙니다.

---

## 5. NLP 기술은 어떻게 발전했을까?

자연어 처리 기술은 단어의 출현 횟수를 세는 방법에서 시작해 문맥을 폭넓게 이해하고 문장을 생성하는 대규모 언어 모델로 발전했습니다.

![NLP 기술의 발전 과정](assets/lec01_05_nlp_history.png)

대표적인 발전 흐름은 다음과 같습니다.

1. **단어 빈도 기반 표현:** 문서에 어떤 단어가 몇 번 등장했는지 계산합니다.
2. **임베딩:** 단어를 의미 관계를 학습할 수 있는 벡터로 표현합니다.
3. **RNN과 LSTM:** 문장을 순서대로 읽으며 앞의 정보를 다음 단계로 전달합니다.
4. **Attention과 Transformer:** 문장 속 여러 단어의 관계를 직접 살펴봅니다.
5. **대규모 언어 모델(LLM):** 대량의 텍스트에서 언어 패턴을 학습하고 다양한 문장을 생성합니다.

새로운 기술이 등장했다고 해서 이전 방법이 항상 필요 없는 것은 아닙니다. 데이터의 크기, 문제의 난이도, 계산 환경에 따라 단순한 방법이 더 적합할 수도 있습니다.

---

## 6. 임베딩: 단어를 숫자 벡터로 표현하기

정수 인코딩으로 만든 토큰 ID는 토큰을 구분하는 번호일 뿐입니다. 모델이 단어 사이의 관계를 학습하려면 각 토큰을 여러 개의 실수로 이루어진 벡터로 바꿔야 합니다. 이 표현을 **임베딩(embedding)**이라고 합니다.

예를 들어 하나의 단어를 다음과 같은 벡터로 나타낼 수 있습니다.

```text
순찰 → [0.18, -0.42, 0.71, 0.09]
```

벡터의 각 숫자에 사람이 직접 의미를 붙이지는 않습니다. 모델은 학습 과정에서 작업에 도움이 되도록 벡터의 값을 조정합니다.

비슷한 문맥에서 자주 사용되는 단어는 임베딩 공간에서 가까운 위치에 놓일 수 있습니다. 예를 들어 `선박`, `배`, `함정`처럼 관련된 단어들이 비교적 가까운 벡터를 가질 수 있습니다.

> **주의:** 임베딩 공간에서 가깝다는 사실만으로 두 단어의 의미가 완전히 같다고 단정할 수는 없습니다. 임베딩은 학습 데이터와 학습 방법의 영향을 받습니다.

---

## 7. RNN과 LSTM: 문장을 순서대로 읽기

문장은 단어의 순서가 중요합니다. **RNN(Recurrent Neural Network)**은 문장을 처음부터 순서대로 읽으면서 이전 단계의 정보를 다음 단계로 전달합니다.

![문장을 순서대로 읽는 RNN과 정보를 기억하는 LSTM](assets/lec01_06_sequence_models.png)

예를 들어 “나는 오늘 학교에 갔다”라는 문장을 처리할 때 RNN은 다음과 같이 작동합니다.

```text
나는 → 오늘 → 학교에 → 갔다
```

각 단계에서는 현재 단어와 이전 단계에서 전달된 정보를 함께 사용합니다. 따라서 현재 단어를 처리할 때 앞에서 어떤 단어가 나왔는지를 반영할 수 있습니다.

그러나 문장이 길어지면 RNN이 앞부분의 정보를 끝까지 유지하기 어려울 수 있습니다. **LSTM(Long Short-Term Memory)**은 이러한 문제를 줄이기 위해 중요한 정보를 오래 유지하고, 불필요한 정보는 줄이는 구조를 사용합니다.

- RNN: 이전 단계의 정보를 다음 단계로 전달합니다.
- LSTM: 중요한 정보를 선택적으로 더 오래 기억하도록 돕습니다.

---

## 8. Attention과 Transformer

**Attention**은 현재 작업에 중요한 단어를 선택적으로 더 참고하는 방법입니다. 문장의 모든 단어를 똑같이 보는 것이 아니라, 예측에 도움이 되는 단어에 더 집중합니다.

예를 들어 “이 선박이 오늘 항구에 도착했다”에서 장소와 관련된 정보를 처리할 때는 `항구`라는 단어가 중요할 수 있습니다.

**Transformer**는 Attention을 중심으로 구성된 모델입니다. RNN처럼 단어를 반드시 하나씩 순서대로 처리하지 않고, 문장 전체에서 단어 사이의 관계를 효율적으로 계산할 수 있습니다.

Transformer는 현재의 번역 모델, 문서 요약 모델, 질의응답 모델, 대규모 언어 모델의 핵심 구조로 널리 사용됩니다.

---

## 9. 언어 모델은 다음 토큰을 예측한다

언어 모델은 주어진 문맥 다음에 어떤 토큰이 나올 가능성이 높은지 계산합니다.

![다음 토큰 예측을 반복하여 문장을 생성하는 과정](assets/lec01_07_language_model.png)

예를 들어 다음 문맥이 주어졌다고 가정해 봅시다.

```text
나는 오늘 학교에
```

모델은 다음 토큰의 확률을 계산합니다.

```text
갔다: 0.58
간다: 0.23
있다: 0.11
기타: 0.08
```

선택된 토큰을 기존 문맥 뒤에 붙이면 새로운 입력이 만들어집니다.

```text
나는 오늘 학교에 갔다
```

모델은 이 문장을 다시 입력으로 사용해 그다음 토큰을 예측합니다. 이 과정을 반복하면 문장이 한 토큰씩 생성됩니다.

> **핵심:** 언어 모델은 완성된 문장을 한 번에 꺼내는 것이 아니라, 다음 토큰 예측을 반복해 문장을 생성합니다.

## 10. 학습과 추론

딥러닝 모델을 사용할 때는 **학습(training)**과 **추론(inference)**을 구분해야 합니다.

| 구분 | 학습 | 추론 |
|---|---|---|
| 목적 | 모델의 가중치 조정 | 학습된 모델로 결과 계산 |
| 입력 | 학습 데이터와 정답 | 새로운 데이터 또는 문맥 |
| 가중치 | 반복적으로 변경됨 | 일반적으로 변경되지 않음 |
| 결과 | 학습된 모델 | 예측, 분류 또는 생성 결과 |

학습 과정에서는 모델의 예측과 정답 사이의 오차를 계산하고, 오차가 줄어들도록 모델의 가중치를 반복해서 조정합니다. 추론 과정에서는 학습이 끝난 모델에 새로운 입력을 넣어 결과를 얻습니다.

쉽게 표현하면 다음과 같습니다.

- **학습:** 모델을 만드는 과정
- **추론:** 만들어진 모델을 사용하는 과정

---

## 11. BERT와 GPT

BERT와 GPT는 모두 Transformer를 기반으로 하지만, 대표적인 학습 방식과 활용 목적에 차이가 있습니다.

| 구분 | BERT | GPT |
|---|---|---|
| 대표 학습 방식 | 가려진 토큰 예측 | 다음 토큰 예측 |
| 활용하는 문맥 | 앞뒤 문맥 | 주로 앞쪽 문맥 |
| 강점 | 문장 이해와 표현 학습 | 텍스트 생성 |
| 대표 활용 | 분류, 정보 추출, 질의응답 | 대화, 요약, 문장 생성 |

BERT는 문장 일부를 가리고 주변 문맥을 이용해 가려진 토큰을 예측하는 방식으로 언어 패턴을 학습합니다.

```text
나는 오늘 [MASK]에 갔다.
```

GPT는 앞에서 주어진 문맥을 이용해 다음 토큰을 예측합니다.

```text
나는 사과를 → 먹었다
```

실제 모델은 버전과 학습 목적에 따라 다양한 방식으로 확장될 수 있습니다. 여기서는 두 모델의 기본적인 차이를 이해하는 데 초점을 둡니다.

## 핵심 정리

- NLP는 사람이 사용하는 언어와 컴퓨터를 연결하는 기술입니다.
- 문장은 토큰화, 정수 인코딩, 벡터 변환을 거쳐 모델의 입력이 됩니다.
- 임베딩은 토큰을 학습 가능한 숫자 벡터로 표현합니다.
- RNN과 LSTM은 문장을 순서대로 처리하며 앞의 정보를 전달합니다.
- Transformer는 Attention을 이용해 문장 안의 단어 관계를 처리합니다.
- 언어 모델은 다음 토큰 예측을 반복하여 문장을 생성합니다.
- 학습은 모델의 가중치를 조정하는 과정이고, 추론은 학습된 모델을 사용하는 과정입니다.
