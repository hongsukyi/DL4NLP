# Lecture 05. 딥러닝 모델 훈련과 성능 평가

딥러닝 모델은 문장에서 특징을 추출해 결과를 예측합니다. 학습 과정에서는 예측과 정답의 차이를 줄이도록 가중치를 조정하고, 평가 과정에서는 새로운 데이터에서도 모델이 잘 작동하는지 확인합니다.

> 이 과정의 실습 코드는 **Keras(TensorFlow)**를 기본으로 합니다. 같은 내용을 PyTorch로 구현한 완성본은 7절 하단의 링크에서 확인할 수 있습니다.

## 학습 목표

- 퍼셉트론과 MLP의 기본 구조를 설명할 수 있습니다.
- MLP, CNN, LSTM·GRU가 활용하는 특징의 차이를 설명할 수 있습니다.
- 임베딩부터 문장 분류까지의 흐름을 설명할 수 있습니다.
- 모델의 학습 과정을 순서대로 설명할 수 있습니다.
- 훈련·검증·테스트 데이터의 역할을 구분할 수 있습니다.
- Loss, Accuracy, 혼동행렬, 학습 곡선을 해석할 수 있습니다.

## 1. 딥러닝 모델의 훈련과 평가

딥러닝 모델을 만드는 과정은 크게 훈련과 평가로 나눌 수 있습니다.

![데이터에서 모델 훈련과 평가까지의 흐름](assets/lec05_01_training_overview.png)

```text
문장 → 특징 추출 → 예측 → 손실 계산 → 가중치 조정 → 성능 평가
```

- **훈련:** 예측 오차를 줄이도록 모델의 가중치를 조정합니다.
- **평가:** 학습에 사용하지 않은 데이터에서도 모델이 잘 작동하는지 확인합니다.

---

## 2. 퍼셉트론과 MLP

퍼셉트론은 여러 입력에 가중치를 곱해 더하고, 편향을 추가하여 결과를 판단하는 초기 신경망 모델입니다.

![퍼셉트론에서 MLP로 확장되는 구조](assets/lec05_02_perceptron_mlp.png)

퍼셉트론의 계산은 다음과 같이 나타낼 수 있습니다.

$$
z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
$$

고전적인 퍼셉트론은 계단함수로 출력을 결정했습니다. 현대 신경망에서는 ReLU, sigmoid처럼 학습에 적합한 활성화함수를 사용합니다.

**MLP(Multi-Layer Perceptron)**는 입력층, 하나 이상의 은닉층, 출력층으로 구성됩니다. 은닉층은 입력을 여러 단계로 변환하며 문제 해결에 필요한 특징을 학습합니다.

---

## 3. 모델마다 활용하는 특징이 다르다

MLP, CNN, LSTM·GRU는 문장에서 서로 다른 특징을 효과적으로 활용합니다.

![MLP, CNN, LSTM이 활용하는 문장 특징 비교](assets/lec05_03_model_comparison.png)

| 모델 | 대표적으로 활용하는 특징 |
|---|---|
| 임베딩 Flatten + MLP | 토큰 위치별 정보를 모두 펼쳐서 사용 |
| 임베딩 평균(GAP) + MLP | 문장 전체의 평균적인 특징 |
| CNN | 인접한 토큰의 지역 패턴 |
| LSTM·GRU | 토큰 순서에 따라 전달되는 정보 |

이는 각 모델의 대표적인 성격을 단순화한 설명입니다. 실제로 활용하는 정보는 모델 구조와 학습 방법에 따라 달라질 수 있습니다.

---

## 4. 이진 분류와 다중 분류

분류는 문장을 미리 정한 범주 중 하나로 구분하는 작업입니다.

| 구분 | 범주 수 | 예 |
|---|---:|---|
| 이진 분류 | 2개 | 긍정 / 부정 |
| 다중 분류 | 3개 이상 | 면접 / 학교 / 협상 |

이진 분류와 다중 분류는 출력층의 구성과 사용하는 손실함수가 다를 수 있습니다. 이번 과정에서는 `면접`, `학교`, `협상`의 세 범주를 구분하는 다중 분류를 사용합니다.

---

## 5. 임베딩에서 문장 분류까지

문장 분류 모델은 토큰 ID를 임베딩 벡터로 변환하고, 여러 토큰의 정보를 하나의 문장 표현으로 요약한 뒤 분류 점수를 계산합니다.

![토큰 ID에서 문장 분류까지의 과정](assets/lec05_04_embedding_to_classification.png)

```text
토큰 ID → 임베딩 → 평균 풀링 → 완전연결층 → 분류 점수
```

- **임베딩:** 각 토큰 ID를 벡터로 변환합니다.
- **평균 풀링:** 여러 토큰 벡터를 하나의 문장 벡터로 요약합니다.
- **완전연결층:** 문장 벡터로 범주별 점수를 계산합니다.

Keras에서는 완전연결층을 일반적으로 `Dense`로 구현합니다. PyTorch에서는 같은 역할을 하는 층을 `nn.Linear`라고 부릅니다.

---

## 6. Flatten과 평균 풀링

Flatten과 평균 풀링은 모두 여러 값을 하나의 벡터로 바꾸지만 처리 방식과 결과 크기가 다릅니다.

![Flatten과 평균 풀링 비교](assets/lec05_05_flatten_mean_pooling.png)

입력의 크기가 `토큰 3개 × 임베딩 2차원`이라고 가정해 봅시다.

| 방법 | 결과 크기 | 특징 |
|---|---:|---|
| Flatten | 6 | 모든 토큰의 값을 한 줄로 연결 |
| 평균 풀링 | 2 | 토큰 방향으로 평균을 계산 |

평균 풀링을 계산할 때 PAD 토큰을 포함하면 문장 벡터가 왜곡될 수 있습니다. 따라서 `attention_mask`를 이용해 실제 토큰만 평균에 포함해야 합니다.

## 7. 모델은 어떻게 학습할까?

모델 학습은 예측과 정답의 차이를 계산하고, 그 차이가 줄어들도록 가중치를 조정하는 반복 과정입니다.

![예측부터 가중치 갱신까지의 학습 순환](assets/lec05_06_training_loop.png)

Keras에서는 `model.fit()`을 호출하면 아래 다섯 단계가 배치마다 자동으로 반복됩니다.

1. 입력을 모델에 넣어 결과를 예측합니다.
2. 예측과 정답을 비교해 손실을 계산합니다.
3. 이전 단계에서 남은 기울기를 초기화합니다.
4. 역전파로 각 가중치의 기울기를 계산합니다.
5. 옵티마이저가 가중치를 갱신합니다.

```python
model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

history = model.fit(
    X_train, y_train,
    validation_data=(X_val, y_val),
    batch_size=32,
    epochs=20,
)
```

`model.fit()` 한 줄이 위 다섯 단계를 여러 배치와 Epoch에 걸쳐 반복해 줍니다.

> **참고:** `tf.GradientTape()`를 사용하면 이 다섯 단계를 직접 코드로 풀어서 볼 수도 있습니다. Keras의 저수준 API(`GradientTape`)는 PyTorch의 `loss.backward()` + `optimizer.step()`과 대응되는 개념입니다. 이번 과정에서는 `model.fit()`으로 충분하므로 자세히 다루지 않습니다.

> **PyTorch 버전:** 이 과정의 완성본 코드를 PyTorch로 구현한 버전은 [PyTorch 버전 보기](#)에서 확인할 수 있습니다. *(링크 준비 중)*

## 8. 훈련·검증·테스트 데이터

전체 데이터를 목적에 따라 훈련, 검증, 테스트 데이터로 나눕니다.

![훈련, 검증, 테스트 데이터의 역할](assets/lec05_07_data_split.png)

| 데이터 | 역할 |
|---|---|
| 훈련 데이터 | 모델의 가중치를 학습하는 데 사용 |
| 검증 데이터 | 모델과 하이퍼파라미터를 선택하는 데 사용 |
| 테스트 데이터 | 선택이 끝난 모델의 최종 성능을 평가 |

테스트 데이터의 결과를 반복해서 보면서 모델을 수정하면 테스트 데이터가 모델 선택에 영향을 주게 됩니다. 따라서 테스트 데이터는 최종 평가 단계에서 사용하는 것이 좋습니다.

---

## 9. Loss와 Accuracy

Loss와 Accuracy는 모두 모델의 상태를 확인하지만 서로 다른 정보를 제공합니다.

| 지표 | 의미 | 역할 |
|---|---|---|
| Loss | 예측과 정답 사이의 오차 크기 | 학습에서 최소화하는 값 |
| Accuracy | 전체 예측 중 정답을 맞힌 비율 | 결과를 직관적으로 평가 |

같은 정답을 선택한 두 모델도 정답에 부여한 확률이 다르면 Loss가 달라질 수 있습니다. Loss는 예측의 확신 정도까지 반영할 수 있기 때문입니다.

범주별 데이터 수가 크게 다르면 Accuracy만으로 성능을 판단하기 어렵습니다. 이때는 혼동행렬과 범주별 recall 등을 함께 확인하는 것이 좋습니다.

---

## 10. 혼동행렬

혼동행렬은 실제 범주와 모델이 예측한 범주를 비교하는 표입니다.

![실제 범주와 예측 범주를 비교하는 혼동행렬](assets/lec05_08_confusion_matrix.png)

- 세로축: 실제 범주
- 가로축: 예측 범주
- 대각선: 올바르게 분류한 수
- 비대각선: 잘못 분류한 수

혼동행렬을 사용하면 전체 Accuracy뿐 아니라 모델이 어떤 범주를 서로 혼동하는지 확인할 수 있습니다.

---

## 11. 학습 곡선과 과적합

학습 곡선은 Epoch에 따른 훈련 손실과 검증 손실의 변화를 보여줍니다.

다음과 같은 현상이 나타나면 과적합을 의심할 수 있습니다.

```text
훈련 손실: 계속 감소
검증 손실: 감소하다가 다시 증가
```

훈련 데이터에는 잘 맞지만 새로운 데이터에 대한 성능이 나빠지는 현상을 **과적합(overfitting)**이라고 합니다. 검증 손실이 일정 기간 개선되지 않으면 학습을 멈추는 조기 종료를 사용할 수 있습니다. Keras에서는 `EarlyStopping` 콜백으로 이를 구현합니다.

```python
early_stop = keras.callbacks.EarlyStopping(
    monitor="val_loss",
    patience=3,
    restore_best_weights=True,
)
```

> 훈련 손실이 감소하는 것 자체는 정상입니다. 훈련과 검증 성능의 차이가 커지는지를 함께 확인해야 합니다.

---

## 12. 학습에서 조절하는 세 가지

### 학습률

한 번의 갱신에서 가중치를 얼마나 크게 변경할지 결정합니다. 너무 크면 학습이 불안정할 수 있고, 너무 작으면 학습이 느려질 수 있습니다.

### 배치 크기

한 번의 가중치 갱신에 사용하는 문장 수입니다. 배치 크기는 학습 속도, 메모리 사용량, 기울기의 변동에 영향을 줍니다.

### Epoch

전체 훈련 데이터를 한 번 모두 확인하는 것을 1 Epoch이라고 합니다. Epoch이 지나치게 많으면 과적합이 발생할 수 있습니다.

---

## 13. 모델을 공정하게 비교하기

모델의 성능을 비교할 때는 가능한 한 평가 조건을 동일하게 유지해야 합니다.

- 같은 데이터 분할을 사용합니다.
- 같은 전처리와 토크나이저를 사용합니다.
- 같은 평가 지표를 사용합니다.
- 처음에는 한 번에 한 가지 조건만 변경합니다.
- 여러 번 실행하여 평균과 변동을 확인합니다.
- 점수와 함께 파라미터 수, 학습 시간, 추론 시간도 기록합니다.

Accuracy가 조금 높더라도 계산량과 학습 시간이 크게 증가한다면 실제 활용에서는 더 좋은 선택이 아닐 수 있습니다.

---

## 14. 학습 전후 문장 표현 살펴보기

모델이 학습되면 분류에 필요한 문장 표현도 달라질 수 있습니다. 고차원 문장 벡터를 t-SNE로 2차원에 표시하면 범주별 군집 경향을 탐색할 수 있습니다.

학습 전후 벡터를 비교할 때는 두 벡터 집합을 합친 뒤 한 번의 t-SNE로 투영하는 방법이 더 적절합니다. 각각 독립적으로 t-SNE를 실행하면 두 그림의 좌표, 방향, 거리를 직접 비교할 수 없습니다.

또한 t-SNE 그림과 실제 분류 성능은 구분해서 해석해야 합니다.

- t-SNE: 벡터 관계를 살펴보는 보조 시각화
- Accuracy와 혼동행렬: 테스트 데이터의 분류 성능 평가

> 군집이 선명해 보인다는 이유만으로 모델의 성능이 우수하다고 단정하지 않습니다.

## 핵심 정리

- MLP는 여러 층을 통해 분류에 필요한 특징을 학습합니다.
- 평균 풀링에서는 PAD를 제외해야 합니다.
- 학습은 예측, 손실 계산, 기울기 초기화, 역전파, 가중치 갱신을 반복하며, Keras에서는 `model.fit()`이 이를 대신 처리합니다.
- 검증 데이터는 모델 선택에, 테스트 데이터는 최종 평가에 사용합니다.
- Loss와 Accuracy는 서로 다른 정보를 제공하므로 함께 확인합니다.
- 과적합은 훈련과 검증 성능의 차이를 통해 판단합니다.
- 모델 비교에서는 데이터, 전처리, 평가 조건을 동일하게 유지해야 합니다.
- t-SNE는 성능 지표가 아니라 표현을 탐색하는 보조 도구입니다.
