# 딥러닝 기반 자연어 처리 입문

이 책은 자연어 처리와 딥러닝의 핵심 개념을 처음 배우는 학습자를 위한 입문 교재입니다.

텍스트가 토큰과 숫자 벡터로 변환되는 과정부터 MLP, 1D CNN, RNN, LSTM, GRU를 이용한 문장 분류까지 단계적으로 학습합니다. 개념 강의와 Keras 기반 실습을 연결하여 모델의 입력, 학습, 평가 과정을 직접 확인할 수 있도록 구성했습니다.

## 주요 학습 내용

- 자연어 처리와 딥러닝의 기본 개념
- 텍스트 전처리, 토큰화, 정수 인코딩
- 워드 임베딩과 문장 벡터 표현
- 딥러닝 모델의 훈련과 성능 평가
- MLP와 1D CNN 기반 문장 분류
- RNN, LSTM, GRU의 구조와 비교
- Google Colab을 이용한 실습

## 책의 구성

- Lecture 01–03: 자연어 처리, 전처리, 임베딩 기초
- Lecture 04: AI Hub 한국어 데이터 전처리 실습
- Lecture 05–07: 모델 훈련, MLP, 1D CNN
- Lecture 08–10: RNN, LSTM, GRU와 비교 실습

## 실습 환경

실습 코드는 Google Colab에서 실행할 수 있습니다. 실습 강의의 본문에 제공된 Colab 링크를 선택하면 별도의 로컬 설치 없이 코드를 실행할 수 있습니다.
